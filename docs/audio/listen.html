Synth and Studio sound packs, side by side

Every track the game plays, the Synth pack (made by the game's own code) next to the Studio pack (generated with ElevenLabs from the prompt shown, then post-processed). Loops repeat between their loop points when "Loop" is ticked. Pick a verdict and write a note for each track; notes stay in this browser. When done, press Export notes and send the text back. Press Play on any track. Open this file in a web browser, or run pnpm listen in the repository and open the address it prints.
