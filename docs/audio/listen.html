Synth, Studio and the 2001 originals, side by side; character voices

Neither sound pack contains the original game's audio. The Synth pack is made by the remaster's own code; the Studio pack was generated with ElevenLabs from the text prompt shown, then post-processed. The original 2001 sounds and music are licensed for the original game only: the game plays them only in museum mode, inside the original client.

The Original (2001) column plays the 2001 game's own sounds, extracted from its Flash files on this machine by pnpm listen:originals for the owner's comparison only. They are not part of either sound pack, are kept outside the repository, and are never committed or distributed. They are paired with the new track that does the same job (from the cue map); one original that served several places is shown beside each. They play only through pnpm listen.

Every track the game plays, Synth next to Studio and, where there is one, the original. Loops repeat between their loop points when "Loop" is ticked; an original loop repeats as many times as the 2001 game repeated it (shown beside it), and one the original repeated 999 times or more repeats continuously. Pick a verdict and write a note for each track; notes stay in this browser. When done, press Export notes and send the text back. Press Play on any track. Open this file in a web browser, or run pnpm listen in the repository and open the address it prints.
